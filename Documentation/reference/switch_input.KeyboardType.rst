switch_input.KeyboardType
=========================

.. class:: switch_input.KeyboardType

   ``IntEnum`` of libnx software keyboard layouts accepted by
   ``switch_input.prompt_keyboard()``.

   Members:

   ``NORMAL``
      Normal keyboard.

   ``NUMPAD``
      Numeric keypad.

   ``QWERTY``
      QWERTY keyboard.

   ``LATIN``
      Latin-language keyboards.

   ``ZH_HANS``
      Simplified Chinese keyboard.

   ``ZH_HANT``
      Traditional Chinese keyboard.

   ``KOREAN``
      Korean keyboard.

   ``ALL``
      All supported language keyboards.
